## v1.0
在 ESP32-MC 基础上进行优化，解决很多 Bug（合成时崩溃等），新增部分功能（!give 命令），经测试使用 ESP32-S3-N16R8 可稳定运行超过 30 分钟。

一个跑在 ESP32-S3 上的极简 Minecraft Java 服务器。

本项目目前主要面向 Arduino ESP32-S3 环境，协议版本为 26.1.2 / 775。整体思路是在资源受限的芯片上，尽量用直接、可追踪的实现，将 Minecraft Java 的基础联机和生存逻辑压到极限。

## 运行方式
在 ESP32-S3 上运行
默认入口为 code.ino。

编译烧录步骤：

用 Visual Studio Code 打开 src/ 目录

安装 PlatformIO，并在 platformio.ini 中设置开发板型号（如 esp32-s3-devkitc-1）

编译并烧录

设备启动后，会开启一个名为 ESP32-MC 的 WiFi 热点（密码同为 ESP32-MC）

服务器开始监听 25565 端口

使用 Minecraft Java 26.1.2 客户端连接 192.168.4.1:25565

启动时串口会输出网络状态、IP 地址和启动信息，方便排查。

也可直接下载 Releases 中的固件，使用烧录工具（如 ESPWebTool）直接烧录。

WiFi 连接
当前使用 AP 热点模式：

WiFi 名称：ESP32-MC

WiFi 密码：ESP32-MC

服务器地址：192.168.4.1:25565

## 目录结构

主要代码位于 src/ 目录：

文件	说明
code.ino	Arduino 入口，初始化串口、WiFi、LED 和主循环
mc_server.cpp/h	服务器主体，连接管理、协议状态机、主要游戏逻辑
packet_codec.cpp/h	Minecraft 数据包编解码
network_layer.cpp/h	ESP32 网络层封装
procedures.cpp/h	玩家行为、方块交互、Mob 和 Tick 逻辑
terrain.cpp/h	地形、区块和基础结构生成
crafting.cpp/h	合成和熔炉逻辑
game_state.cpp/h	全局游戏状态
game_types.h	主要常量、开关和数据结构
registries.cpp/h	协议注册表和相关大体积数据
wifi_config.cpp/h	WiFi 保存和串口配网逻辑（当前未使用）
## 开发说明
